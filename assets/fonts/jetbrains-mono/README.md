# JetBrains Mono

Official JetBrains Mono v2.304 webfonts, self-hosted by BCBD Wiki.

Source: https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/webfonts
License: SIL Open Font License 1.1 (see `OFL.txt`).

Regular, Medium, SemiBold, Bold and ExtraBold preserve the site's existing weight
hierarchy. Italic and BoldItalic cover emphasis in content. The browser downloads
only the faces it uses. `css/styles.css` supplies this family to every page,
including native form controls, code, the 3D viewer and map controls.

Font URLs are relative to the stylesheet, so nested routes and a GitHub Pages
repository prefix work without installing a font on the visitor's device.
Emoji and symbols outside JetBrains Mono's character set use browser font fallback.
Text baked into images, PDFs or raster map tiles remains part of those assets.
