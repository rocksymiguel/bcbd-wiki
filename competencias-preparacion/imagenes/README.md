# Recursos nuevos de competencias

Los nueve SVG describen solo la secuencia existente de cada estación, sin distancias ni plano oficial. Se crearon para esta Wiki.

Las fotos se descargaron de Wikimedia Commons, se recortaron para conservar ejercicio, equipo y objetivo, y se guardan localmente. Las fuentes de Commons las identifican como dominio público en EE.UU. Los créditos y fuentes aparecen en las páginas.

- `kaiser.jpg`: U.S. Air Force, Brittany Bateman/Auld. https://commons.wikimedia.org/wiki/File:Fire_Prevention_Week_121012-F-RB551-219.jpg
- `piton.jpg`: U.S. Navy, Miles McDonough. https://commons.wikimedia.org/wiki/File:Firefighters_conduct_hose_accuracy_drill_during_competition_exercise_at_outdoor_training_facility_(9877198).jpg

Las ilustraciones anteriores permanecen como originales en `../illustraciones/`, pero las páginas ya no las utilizan.
